# Sounds the port adds

Source clips for `tools/add_port_sounds.py`, which adds them to the sound catalog and writes the
game's clip files.

* `wilhelm.flac`: the Wilhelm scream, the fourth scream of the original 1951 Sunset Editorial
  recording session "Man eaten by alligator; screams", released into the public domain (CC0 1.0)
  by the USC School of Cinematic Arts. The session is on the Internet Archive
  (https://archive.org/details/SSE_Library_VOICES, SCREAM folder) and Freesound
  (https://freesound.org/people/craigsmith/sounds/675810/).
  `python tools/add_port_sounds.py --wilhelm SESSION.flac` cuts it again from the session.
